# Контроль качества 0.5
Design DNA: четыре пользовательских эталона от 22.11.2026. Desktop — панель режимов, PV-баннер, семь показателей, три колонки, нижняя навигация. Mobile — четыре плитки, текущие работы, нижняя навигация. Case — фотография крыши, готовность, три показателя, список этапов. Garage — баннер склада, поиск позиций, карточки и движения. Статусы и цифры берутся из модели. Визуальная проверка: открыть эти четыре экрана при 375 и 1440 px, сверить композицию, контраст, активный пункт и отсутствие перекрытия кнопок.
 
Memory of Mistakes: корневой адрес и README расходились — использовать прямой URL. У материала раньше был обязательный город — поля зависят от операции. Доступ к приёмке раньше давала кнопка — роль, назначение и статус проверяются внутри модели. Повреждённую запись защищает режим восстановления, импорт сначала проверяет схему.
 
Functional QA: node model.test.cjs. Browser QA: python browser_qa.py URL с установленным Playwright и Chromium, либо ENGINE=webkit. Каждый прогон создаёт отдельный временный контекст. Проверяются четыре размера, создание Case и Shard, выдача, передача и приёмка, сохранение, экспорт/импорт, отмена, повторная загрузка без сети.

Time Machine: настройки → отменить последнюю операцию. Снимки находятся в той же атомарной записи, что и данные. Перед крупной серией тестов экспортируйте JSON. Тесты CI используют собственный origin. Для отката кода вернуть конкретный коммит через git revert; перед откатом на исходную v1 экспортировать локальные данные, поскольку v1 не понимает новую схему.

Настройки → Тестовая копия копирует текущий набор в отдельное пространство браузера. Жёлтая полоса маркирует все тестовые экраны. Возврат к рабочим данным переключает пространство, и тестовые операции не переносятся. Добавлена регрессия создания тестового Case с последующим возвратом к рабочему профилю. Пять фото карточек Garage взяты из подтверждённых эталонов; новый материал получает текстовую карточку.

## Desktop Command
Последний присланный Desktop Command закреплён как эталон. В рабочие карточки встроены три отдельные фотографии машин, локальные остатки определяют их статус. Доля загрузки — исполнители с открытым назначением / число участников. Кнопки нижней панели используют контурные пиктограммы. В отчёте CI сохраняются снимки Dashboard, Case и Garage каждого размера и движка.
Офлайн-тест с локальным сервером полностью выключает HTTP-сервер перед reload. Это воспроизводит отсутствие origin без зависимости от реализации эмуляции сети WebKit.
