# NVTSK SYSTEM · SILVER CAREER MODE · MVP 0.3

**NVTSK SYSTEM** — прототип управления PV-проектами и монтажными бригадами, оформленный как карьерная игра. Главные файлы: `index.html`, `v03.js`, `v03.css`, `gameplay.js`, `gameplay.css`.

Планируемый адрес GitHub Pages: https://nvtsk18.github.io/nvtsk_system/  
Если публичная версия не обновилась, проверь GitHub Pages Settings → Deploy from branch → `main` → `/(root)` и обнови Safari.

## Реализовано в локальной демоверсии

- **Silver UI**: графитовый фон, серебристые элементы, карточки в стиле игрового HUD, адаптивная мобильная навигация, переходы справа/слева и свайп между разделами (с уважением к `prefers-reduced-motion`).
- **Персонаж и регистрация**: локальная форма создания демоперсонажа, выбор игровой роли, кабинет, аватар, характеристики, XP, Legacy, Merit, косметические облики, карьерная лестница и достижения.
- **Mission Board**: PV-лоты как миссии, условия допуска, начало, прогресс по фотоэтапам, завершение с единовременной наградой XP / Merit и игровыми очками влияния региона.
- **Crew Garage**: инструменты, бус, RSS/Dachschutz, подъёмник и оснащение. Отметки демонстрационные, реальные сертификаты и безопасность не подтверждают.
- **Skill Tree**: монтаж, безопасность, логистика, руководство, AC Knowledge. Ранг не даёт электротехнического допуска.
- **Alliances & Raids**: большой лот как рейд, распределение ролей между Projektierung, DC, AC и Anmeldung, планировщик команды.
- **Wanted Board**: условная потребность в специалистах из лотов, демонстрационный локальный отклик.
- **Seasons & Territory**: тестовая таблица лидеров, влияние в городе и задания с наградами.
- **Социальная лента**: посты, медиа, комментарии, лайки, подписки, уведомления. Есть локальные чаты объектов.
- **Merit Wallet**: условный баланс, резерв MentorGate, расходы на косметику, история операций. 1 Merit = 0,01 € **только как расчётная игровая модель**, без обмена и выплат.
- **Проекты**: создание и редактирование лотов/сублотов, разделение на 4 этапа, фото «до» и «после», PDF прямо в браузере, страницы документа по этапам, лента объекта, адреса и ссылка на навигацию.
- **Сохранение**: данные в localStorage; медиа и PDF в IndexedDB **только этого браузера**, резервный JSON-экспорт без медиа.

## Важные ограничения

Это **не настоящая регистрация с защищённым аккаунтом**, **не платёжный кошелёк** и **не многопользовательская платформа**. Для работы между телефонами необходимы backend, авторизация, разграничение прав, серверная база, защищённое хранилище файлов, уведомления, аудит и резервные копии. Демо-режим не подтверждает квалификацию Elektrofachkraft, не отправляет отклики или сообщения работодателям и не принимает реальные оплаты.

Игровой XP, Legacy, Merit и Territory REP не заменяют правовые или профессиональные требования. Внутрисистемные баллы сами по себе не исключают налоговое и иное правовое регулирование реальных выплат.

Представленные названия компаний и проекты — **демонстрационные карточки**; никто из этих компаний не зарегистрирован в прототипе по подтверждённой информации. Оригинальные проектные PDF не опубликованы в репозитории. Подробные планы реальных объектов нужно размещать в защищённой базе с разрешённым доступом.

## Проверка

Проверен JavaScript-синтаксис обоих скриптов и запуск ключевых экранов в тестовой среде, включая локальную регистрацию, игровые разделы, завершение миссии, социальную публикацию и косметику. **Полная проверка реального iPhone Safari и доступности опубликованного GitHub Pages ещё требуется.**
