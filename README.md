# NVTSK SYSTEM · Silver MVP 0.3

Новая единая версия в ветке **main**: [index.html](./index.html), [v03.css](./v03.css), [v03.js](./v03.js).

## Что доступно в текущей демоверсии

- Стилизованный адаптивный интерфейс: графитовый фон, холодные серебристые акценты, карточки и мобильная навигация.
- Экран обзора и управление проектами: создание объектов, дочерние сублоты с наследованием адреса и заказчика, автоматическое деление на Projektierung, DC-Montage, AC-Anschluss, Anmeldung. У каждого собственные статус, бюджет и исполнитель.
- Биржа лотов и тестовые ставки. При обновлении с 0.2 предшествующие ставки из localStorage импортируются в демо.
- Фото-чек-листы по видам работ: Dachschutz, Unterkonstruktion, Module, DC/Stringplan, Erdung, Dachausgang/Kabelkanal, Wechselrichter/AC, Anmeldung и Zusatzarbeiten. К задачам можно привязывать фото до/после и номер страницы PDF.
- Загрузка PDF, просмотр документа в браузере, наследование документов от родительского объекта.
- Лента объекта с постами, фотографиями и комментариями, а также локальные чаты по объектам.
- Личные профили, аватары, телефоны и ссылки на звонок/WhatsApp, показатели навыков, история проектов и операций Merit.
- Команда с капитаном, несколькими администраторами и тестовыми приглашениями.
- MentorGate с резервированием 1 000 / 2 500 Merit и демонстрационным обучением новичка. Legacy нельзя купить; демо-репутация привязывается к приёмке фотоэтапа.
- Симуляция чаевых заказчика, курс 1 Merit = 0,01 €. Это не настоящая оплата, конвертация или юридическое определение налогового статуса.
- Демонстрационные шаблоны проектов HN17, HN19 и примеров с названиями Sanpower, 5-Sterne-Solar, Solan Plus GmbH, Kempter GmbH. **Эти компании не имеют подтверждённых аккаунтов и не давали согласия на публикацию своих рабочих материалов. Оригинальные PDF не загружены.**

## Как открыть

При опубликованном GitHub Pages: https://nvtsk18.github.io/nvtsk_system/

Если публикация не настроена, открой репозиторий через GitHub Pages Settings, выбери `Deploy from a branch`, `main`, `/(root)` и сохрани. Открывай адрес в браузере, а не файл исходного HTML в просмотрщике GitHub.

Не скачивай один `index.html`: для работы нужны также `v03.css` и `v03.js` в той же директории.

## Важно: это MVP, не рабочая SaaS-платформа

- Текстовые данные хранятся в localStorage браузера; фото и PDF сохраняются в IndexedDB **на том же устройстве**. Между телефонами ничего не синхронизируется.
- Нужны backend, аутентификация, роли заказчика/подрядчика, разграничение доступа, настоящие групповые чаты и проверка специалистов для AC/Netzbetreiber.
- Приёмка, торги, чаевые, Merit, MentorGate и репутация пока имитируются. Реальных денег, заказов, выплат, проверок личности и регистрации Anmeldung не происходит.
- Оригиналы трёх проектов и страницы схем нужно импортировать через защищённое хранилище с учётом конфиденциальных данных, а не размещать в публичном GitHub.
- На текущем этапе пройдены проверки синтаксиса JavaScript и рендеринга основных экранов в тестовой среде. Проверка настоящего Safari на iPhone и развёрнутого GitHub Pages не завершена.
