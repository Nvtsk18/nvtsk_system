# NVTSK SYSTEM 0.5

[Открыть Silver Command 0.5](https://nvtsk18.github.io/nvtsk_system/silver-command-05/). Рабочая директория — `silver-command-05/`.

## Архивная документация 0.4

## Назначение

Local-first браузерный MVP для внутреннего управления PV-проектами: Case → Shard → исполнители → Garage → документы и фото → демоприёмка → Project Pulse.

Все данные сохраняются локально в браузере. Нет серверной авторизации, синхронизации между устройствами, юридической приёмки и финансовых операций. Не используйте реальные клиентские персональные данные.

## Разработка

Основной код: `silver-command/index.html`, `app.js`, `style.css`, `garage.js`, `stage-domain.js`. Проверки и ограничения: `silver-command/AUDIT_LOG.md`. Старые интерфейсы удалены из текущей ветки.
