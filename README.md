# NVTSK SYSTEM · MVP 0.3

Основная версия приложения: [index.html](./index.html).

## Что можно попробовать

- Существующие демонстрационные лоты, карта, ставки, команда, сообщество.
- Новый раздел **Проекты 0.3**: создание проекта, копирование лота на основе предыдущего, вложенные сублоты и четыре типовых направления: Projektierung, DC-Montage, AC-Anschluss, Anmeldung.
- У каждого сублота отдельные бюджет, исполнитель, статус, фото-чек-лист, комментарии и PDF. Адрес и сведения о заказчике наследуются из родительского лота.
- Фото до/после и условная приёмка заказчиком. Загрузка PDF и просмотр прямо в браузере.
- Демонстрационный профиль, условные Merit, адрес для навигации.

## Как открыть

Скачайте файл `index.html` и откройте в браузере с разрешённым JavaScript. GitHub Code Preview показывает исходник, но сам по себе **не** запускает приложение. Наличие опубликованного GitHub Pages сайта не подтверждено.

## Ограничения

Это **прототип**, а не рабочая многопользовательская SaaS-платформа. Данные задач и сообщений хранятся в LocalStorage конкретного браузера, а выбранные изображения/PDF пока доступны только в текущем сеансе. Заказчик и исполнитель не синхронизируются по сети, права доступа и настоящие платежи отсутствуют. Для использования с реальными клиентами потребуются сервер, аутентификация, БД, защищённое файловое хранилище, аудит и проверка полномочий специалистов.

В репозиторий не загружаются персональные данные собственников и исходные PDF-проекты без отдельного согласования.
